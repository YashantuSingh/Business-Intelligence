## 📊 Project Summary

This repository presents an interactive **Superstore Retail Performance Analysis Dashboard** built using **Power BI**, designed to provide deep insights into sales, profit, and customer behavior across different regions and categories.

The dashboard enables users to explore key retail metrics, analyze trends, and evaluate performance across multiple dimensions such as **state, segment, category, and shipping mode**.

---

## 🚀 Key Highlights

* 📈 **Sales & Profit Analysis** across regions (Central, East, South, West)
* 🛒 **Category & Sub-Category Insights** (Furniture, Technology, Office Supplies)
* 👥 **Customer Segmentation Analysis** (Consumer, Corporate, Home Office)
* 💳 **Payment Mode Distribution** (COD, Cards, Online)
* 🌍 **Geographical Analysis** with map-based state-level insights
* 🚚 **Shipping Mode Comparison** (Standard, First Class, Second Class, Same Day)
* 📊 **Monthly Trends** for sales and profit tracking

---

## 🧰 Tools & Technologies

* **Power BI Desktop**
* **Microsoft Excel / CSV Dataset**
* **Power Query** (data transformation & cleaning)

---

## 📊 Key Insights

* Identification of **top-performing states** like California and New York
* Analysis of **high-profit and high-sales regions**
* Understanding **customer segment contribution** to overall sales
* Evaluation of **shipping modes and delivery efficiency**
* Monthly trends highlighting **seasonality in sales and profit**

---

## 📌 Purpose

The goal of this project is to demonstrate **business intelligence, data visualization, and analytical skills** by converting raw retail data into meaningful and actionable insights through an interactive dashboard.
