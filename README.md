## 📈 Dashboard Features

* 📊 **KPI Cards** for key metrics (Sales, Profit, Quantity, etc.)
* 🎛️ **Slicers** for dynamic filtering (Category, Date, Region)
* 📉 **Trend Analysis** using line and bar charts
* 🖼️ **Image Integration** for enhanced storytelling
* 📋 **Tabular View** for detailed data exploration

---

## 🚀 How to Use

1. Download the `.pbix` file from the `dashboard/` folder
2. Open it using **Power BI Desktop**
3. If prompted, update the data source path to match your local Excel file
4. Use filters and visuals to explore the dashboard
