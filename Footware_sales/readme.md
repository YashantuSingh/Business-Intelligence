## 📊 Project Summary

This repository features an interactive **Footwear Sales Dashboard** built using **Power BI**, designed to analyze and visualize sales performance across products, regions, and sales channels.

The dashboard provides a comprehensive view of key business metrics such as **total sales, operating profit, and profit margins**, enabling users to identify trends, compare regional performance, and evaluate product-level insights.

---

## 🚀 Key Highlights

* 📈 **Sales & Profit Analysis** across multiple regions (Midwest, Northeast, South, Southeast, West)
* 🛍️ **Product Performance Insights** for different footwear categories
* 🏬 **Retailer Comparison** to evaluate operating margins
* 🌍 **Geographical Visualization** using map-based analysis
* 🎯 **Dynamic Filters** for sales methods (In-store, Online, Outlet)
* 📊 **Interactive Charts** including bar, donut, and trend visuals

---

## 🧰 Tools & Technologies

* **Power BI Desktop**
* **Microsoft Excel** (data source)
* **Power Query** (data transformation)

---

## 📊 Key Insights

* Regional differences in **sales and profitability**
* Identification of **top-performing products and retailers**
* Trends in **operating margins across sales channels**
* Distribution of **units sold across regions**

---

## 📌 Purpose

The goal of this project is to demonstrate **data visualization, dashboard design, and business intelligence skills** by transforming raw data into actionable insights through an intuitive and interactive interface.
